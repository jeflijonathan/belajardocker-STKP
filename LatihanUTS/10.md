Dalam sistem terdistribusi tidak ada jam global bersama. Setiap node memiliki jam fisik sendiri yang mengalami **clock drift**, yaitu laju jam yang menyimpang dari waktu referensi (sekitar 10⁻⁶ atau 1 µs per detik pada kristal biasa). Akibatnya muncul **clock skew**, yaitu selisih pembacaan jam antar node pada suatu instan.

Contoh:

Node A = **3:00:00**

Node B = **2:59:55**

Node C = **3:00:02**

Node A Kirim -> Node B Terima -> Node B Kirim -> Node C Terima

| Proses        | Posisi Node | Physical Clock |
| :------------ | :---------- | :------------- |
| Node A Kirim  | A           | 3:00:00        |
| Node B Terima | B           | 2:59:55        |
| Node B Kirim  | B           | 2:59:55        |
| Node C Terima | C           | 3:00:02        |

Jika skenario tersebut dibaca menggunakan urutan waktu (Physical Clock) maka **tidak mungkin** B menerima pesan **sebelum** A mengirimnya, yang mustahil secara logika.

Ada dua pendekatan untuk mengatasinya:

- **Physical clock**: menyinkronkan jam agar mendekati waktu sebenarnya (UTC) atau saling mendekati antar node.

- **Logical clock**: tidak peduli waktu sebenarnya, hanya menjaga **urutan kejadian** (ordering) yang konsisten.

# Physical Clock

## Cristian's Algorithm

Sinkronisasi eksternal, berbasis client-server. Server waktu (_time server_) dianggap memiliki sumber waktu akurat (misalnya penerima UTC).

_round-trip time_(RTT) = T₁ − T₀

Waktu baru = T_server + RTT/2

contoh:

- Client kirim permintaan pada T₀ = 10:00:00.000

- Client terima balasan pada T₁ = 10:00:00.100

- Waktu Server = 10:00:05.000

- Waktu baru = **10:00:05.050**

Jika terdapat banyak client maka RTT akan bervariasi, namun diingat yang butuh sinkronisasi adalah client terhadap server bukan antar client.

## Berkeley Algorithm

sinkronisasi internal. Tujuannya agar jam antar node saling konsisten, bukan sesuai UTC. Cocok untuk jaringan tanpa sumber waktu eksternal.

contoh:

| Node        | Selisih | Koreksi                 |
| :---------- | :------ | :---------------------- |
| Master 3:00 | 0       | +5 - 0 = +5 = 3:05      |
| Node A 3:25 | +25     | +5 - 25 = -20 = 3:05    |
| Node B 2:50 | -10     | +5 - (-10) = +15 = 3:05 |

Waktu rata-rata = (0 + 25 - 10) / 3 = +5

## Network Time Protocol

Protokol sinkronisasi eksternal skala Internet, berjalan di atas UDP port 123, dengan struktur hierarkis.

$Offset θ = [(T₂ − T₁) + (T₃ − T₄)] / 2$

$Delay δ = (T₄ − T₁) − (T₃ − T₂)$

- T₁: client mengirim permintaan

- T₂: server menerima

- T₃: server mengirim balasan

- T₄: client menerima

---

contoh:

- T₁ = 3:00:00:00.100 ms (jam client)

- T₂ = 3:00:00:00.160 ms (jam server)

- T₃ = 3:00:00:00.165 ms (jam server)

- T₄ = 3:00:00:00.125 ms (jam client)

---

```text
θ = [(160 − 100) + (165 − 125)] / 2
  = (60 + 40) / 2
  = 50 ms  → jam client harus maju 50 ms

Jam client baru = T₄ + θ
= 10:00:00.125 + 50 ms
= 10:00:00.175

δ = (125 − 100) − (165 − 160)
  = 25 − 5
  = 20 ms  → waktu murni di jaringan (pergi + pulang).
```

# Logical Clock

## Lamport

Lamport clock tidak mengukur waktu. Setiap node hanya menyimpan satu angka **L** (counter), yang dipakai untuk mengurutkan kejadian. Aturannya hanya dua:

1. **Setiap ada kejadian (lokal atau kirim pesan):** `L = L + 1`. Pesan yang dikirim membawa nilai L itu.

2. **Saat menerima pesan** dengan timestamp `t`: `L = max(L, t) + 1`.

| Event                 | L(A)  | L(B)  | L(C)  | Keterangan               |
| :-------------------- | :---- | :---- | :---- | :----------------------- |
| Kondisi Awal          | **0** | **0** | **0** |                          |
| A kirim pesan ke B    | **1** |       |       | L(A) = 0 + 1 = 1, ​t=1   |
| B terima pesan dari A |       | **2** |       | L(B) = max(0, 1) + 1 = 2 |
| B kirim pesan ke C    |       | **3** |       | L(B) = 2 + 1 = 3, ​t=3   |
| C terima pesan dari B |       |       | **4** | L(C) = max(0, 3) + 1 = 4 |
| A kirim pesan ke B    | **2** |       |       | L(A) = 1 + 1 = 2, ​t=2   |
| B terima pesan dari A |       | **4** |       | L(B) = max(3, 2) + 1 = 4 |
| B kirim pesan ke C    |       | **5** |       | L(B) = 4 + 1 = 5, ​t=5   |
| C terima pesan dari B |       |       | **6** | L(C) = max(4, 5) + 1 = 6 |

Node D Kirim -> Node B Terima -> Node B Kirim -> Node C Terima

| Event                 | L(D) | L(B) | L(C) | Keterangan                 |
| :-------------------- | :--- | :--- | :--- | :------------------------- |
| Kondisi Awal          | 10   | 5    | 6    |                            |
| D kirim pesan ke B    | 11   |      |      | L(D) = 10 + 1 = 11, ​t=11  |
| B terima pesan dari D |      | 12   |      | L(B) = max(5, 11) + 1 = 12 |
| B kirim pesan ke C    |      | 13   |      | L(B) = 12 + 1 = 13, ​t=13  |
| C terima pesan dari B |      |      | 14   | L(C) = max(6, 13) + 1 = 14 |

`master.py`

```python
import os, time, threading
from datetime import datetime
from xmlrpc.client import ServerProxy

offset = float(os.getenv("OFFSET", "0"))
SLAVES = ["presentation", "application"]   # nama container slave

def now():
    return time.time() + offset

def sync():
    global offset
    time.sleep(5)
    node = {n: ServerProxy(f"http://{n}:5000") for n in SLAVES}
    while True:
        diff = {n: p.now() - now() for n, p in node.items()}   # selisih vs master
        diff["master"] = 0.0
        avg = sum(diff.values()) / len(diff)
        print(f"\nselisih: { {n: round(d, 1) for n, d in diff.items()} } | rata-rata: {avg:+.1f} s")
        offset += avg                                          # koreksi master
        for n, p in node.items():
            p.adjust(avg - diff[n])                            # kirim koreksi slave
        time.sleep(15)

threading.Thread(target=sync, daemon=True).start()

while True:
    print("Jam Sekarang:", datetime.fromtimestamp(now()).strftime("%H:%M:%S"), end="\r", flush=True)
    time.sleep(1)
```

```python
import os, time, threading
from datetime import datetime
from xmlrpc.server import SimpleXMLRPCServer

offset = float(os.getenv("OFFSET", "0"))

def now():
    return time.time() + offset

def adjust(delta):
    global offset
    offset += delta
    print(f"\nkoreksi {delta:+.1f} s")
    return True

server = SimpleXMLRPCServer(("0.0.0.0", 5000), logRequests=False)
server.register_function(now)
server.register_function(adjust)
threading.Thread(target=server.serve_forever, daemon=True).start()

while True:
    print("Jam Sekarang:", datetime.fromtimestamp(now()).strftime("%H:%M:%S"), end="\r", flush=True)
    time.sleep(1)
```

## Lamport

`lamport.py`

```python
import os
import time

class LamportClock:
    def __init__(self, nama):
        self.nama = nama
        self.waktu = 0
        self.offset = int(os.environ.get("OFFSET", "0"))

    def jam_fisik(self):
        t = time.time() + self.offset
        return time.strftime("%H:%M:%S", time.localtime(t))

    def _log(self, pesan):
        print(
            f"{pesan}",
            flush=True,
        )

    def kirim(self, tujuan):
        lama = self.waktu
        self.waktu += 1
        self._log(f"KIRIM  ke {tujuan:<12}  L = {lama}+1 = {self.waktu}")
        return self.waktu

    def terima(self, asal, ts_masuk):
        lama = self.waktu
        self.waktu = max(lama, ts_masuk) + 1
        self._log(
            f"TERIMA dari {asal:<12} "
            f"L = max({lama}, {ts_masuk})+1 = {self.waktu}"
        )
        return self.waktu
```

`database.py`

```python
from xmlrpc.server import SimpleXMLRPCServer
from lamport import LamportClock

clock = LamportClock("DATABASE")

users = {
    1: {"id": 1, "nama": "Andi", "umur": 20},
    2: {"id": 2, "nama": "Budi", "umur": 22},
}

def get_all():
    return list(users.values())

def get_by_id(user_id):
    return users.get(user_id)

def insert(user_id, nama, umur):
    if user_id in users:
        return False

    users[user_id] = {
        "id": user_id,
        "nama": nama,
        "umur": umur
    }
    return True

def delete(user_id):
    if user_id not in users:
        return False

    del users[user_id]
    return True

def dengan_lamport(fungsi):
    def wrapper(ts, *args):
        clock.terima("application", ts)
        hasil = fungsi(*args)
        ts_balas = clock.kirim("application")
        return {"ts": ts_balas, "hasil": hasil}
    return wrapper

server = SimpleXMLRPCServer(
    ("0.0.0.0", 8004),
    allow_none=True,
    logRequests=False
)

server.register_function(dengan_lamport(get_all), "get_all")
server.register_function(dengan_lamport(get_by_id), "get_by_id")
server.register_function(dengan_lamport(insert), "insert")
server.register_function(dengan_lamport(delete), "delete")

print("Database Tier aktif di port 8004", flush=True)
server.serve_forever()
```

`application.py`

```python
import os
from xmlrpc.server import SimpleXMLRPCServer
import xmlrpc.client
from lamport import LamportClock

clock = LamportClock("APPLICATION")

database = xmlrpc.client.ServerProxy(
    f"http://{os.environ.get('DB_HOST', 'database')}:8004/",
    allow_none=True
)

def panggil_database(nama_fungsi, *args):
    ts = clock.kirim("database")
    resp = getattr(database, nama_fungsi)(ts, *args)
    clock.terima("database", resp["ts"])
    return resp["hasil"]

def buat_handler(nama_rpc, fungsi_db):
    def handler(ts, *args):
        clock.terima("presentation", ts)
        hasil = panggil_database(fungsi_db, *args)
        ts_balas = clock.kirim("presentation")
        return {"ts": ts_balas, "hasil": hasil}
    return handler

server = SimpleXMLRPCServer(
    ("0.0.0.0", 8000),
    allow_none=True,
    logRequests=False
)

server.register_function(buat_handler("tampilkan_users", "get_all"), "tampilkan_users")
server.register_function(buat_handler("cari_user", "get_by_id"), "cari_user")
server.register_function(buat_handler("tambah_user", "insert"), "tambah_user")
server.register_function(buat_handler("hapus_user", "delete"), "hapus_user")

print("Application Server berjalan di port 8000", flush=True)
server.serve_forever()
```

```python
import os
import xmlrpc.client
from lamport import LamportClock

clock = LamportClock("PRESENTATION")

server = xmlrpc.client.ServerProxy(
    f"http://{os.environ.get('APP_HOST', 'application')}:8000/",
    allow_none=True
)

def panggil(nama_rpc, *args):
    print(f"\n--- Lamport trace: {nama_rpc} ---", flush=True)
    ts = clock.kirim("application")
    resp = getattr(server, nama_rpc)(ts, *args)
    clock.terima("application", resp["ts"])
    print("--- selesai ---", flush=True)
    return resp["hasil"]

while True:
    print("\n=== APLIKASI ===")
    print("1. Tampilkan semua user")
    print("2. Cari user berdasarkan ID")
    print("3. Tambah user")
    print("4. Hapus user")
    print("5. Keluar")

    try:
        pilihan = input("Pilih menu: ")
    except EOFError:
        break

    try:
        if pilihan == "1":
            users = panggil("tampilkan_users")

            for user in users:
                print(user)

        elif pilihan == "2":
            user_id = int(input("Masukkan ID: "))
            user = panggil("cari_user", user_id)

            print(user if user else "User tidak ditemukan")

        elif pilihan == "3":
            user_id = int(input("ID: "))
            nama = input("Nama: ")
            umur = int(input("Umur: "))

            hasil = panggil("tambah_user", user_id, nama, umur)

            if hasil:
                print("User berhasil ditambahkan")
            else:
                print("ID sudah digunakan")

        elif pilihan == "4":
            user_id = int(input("ID yang akan dihapus: "))
            hasil = panggil("hapus_user", user_id)

            if hasil:
                print("User berhasil dihapus")
            else:
                print("User tidak ditemukan")

        elif pilihan == "5":
            print("Program selesai.")
            break

        else:
            print("Pilihan tidak valid.")

    except ConnectionRefusedError:
        print("Koneksi gagal. Pastikan kedua server aktif.")

    except Exception as e:
        print("Terjadi kesalahan:", e)
```
