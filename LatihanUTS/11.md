# #11 Distributed Mutual Exclusion and Leader Election

# Koordinasi eksklusif antar node

Koordinasi eksklusif adalah mekanisme untuk memastikan bahwa hanya satu node yang dapat mengakses _Critical Section_ (sumber daya bersama seperti basis data, berkas, atau perangkat keras) pada satu waktu tertentu, guna menghindari kondisi balapan (_race condition_) dan inkonsistensi data. adapun syarat utamanya adalah:

- Safety: Tidak ada dua node yang berada di dalam _Critical Section_ secara bersamaan.

- Liveness (Keaktifan): Permintaan untuk masuk atau keluar dari _Critical Section_ pada akhirnya harus diproses (bebas dari _deadlock_ dan _starvation_).

- Fairness: Permintaan harus dilayani sesuai urutan kedatangan (biasanya berbasis _Lamport timestamp_).

## Token Ring

_Token Ring_ adalah salah satu pendekatan terdistribusi untuk _mutual exclusion_ di mana node-node disusun dalam **topologi cincin logis** (_logical ring_). Berjalan di arsitektur sistem terdistribusi peer-to-peer atau beberapa node di dalam satu tier yang sama.

## Database-Level Locking

Jika perebutan data terjadi pada level data yang disimpan, industri sering kali menyerahkan pengamanannya langsung ke sistem manajemen basis data (DBMS).

- **Pessimistic Locking:** Menggunakan perintah seperti `SELECT ... FOR UPDATE` agar baris data di database langsung dikunci begitu dibaca oleh satu node aplikasi, sehingga node lain tidak bisa mengubahnya sampai transaksi selesai.

- **Optimistic Locking:** Menggunakan kolom versi/timestamp pada tabel database untuk mendeteksi apakah data sudah diubah oleh node lain sebelum disimpan.

`database.py`

```python
import threading
from xmlrpc.server import SimpleXMLRPCServer

users = {
    1: {"id": 1, "nama": "Andi", "umur": 20},
    2: {"id": 2, "nama": "Budi", "umur": 22},
}

db_lock = threading.Lock()

def get_all():
  with db_lock:
    return list(users.values())

def get_by_id(user_id):
  with db_lock:
    return users.get(user_id)

def insert(user_id, nama, umur):
  with db_lock:
    if user_id in users:
      return False

    users[user_id] = {"id": user_id, "nama": nama, "umur": umur}
    return True

def delete(user_id):
  with db_lock:
    if user_id not in users:
      return False

    del users[user_id]
    return True

server = SimpleXMLRPCServer(("0.0.0.0", 8004), allow_none=True)
server.register_function(get_all, "get_all")
server.register_function(get_by_id, "get_by_id")
server.register_function(insert, "insert")
server.register_function(delete, "delete")

print("Database Tier aktif di port 8004", flush=True)
server.serve_forever()
```

`application.py`

```python
from xmlrpc.server import SimpleXMLRPCServer
import xmlrpc.client

database = xmlrpc.client.ServerProxy(
    "http://database:8004/",
    allow_none=True
)

def tampilkan_users():
    return database.get_all()

def cari_user(user_id):
    return database.get_by_id(user_id)

def tambah_user(user_id, nama, umur):
    return database.insert(user_id, nama, umur)

def hapus_user(user_id):
    return database.delete(user_id)

server = SimpleXMLRPCServer(
    ("0.0.0.0", 8000),
    allow_none=True
)

server.register_function(tampilkan_users, "tampilkan_users")
server.register_function(cari_user, "cari_user")
server.register_function(tambah_user, "tambah_user")
server.register_function(hapus_user, "hapus_user")

print("Application Server berjalan di port 8000", flush=True)
server.serve_forever()
```

import concurrent.futures
import xmlrpc.client

APP_NODES = [
    "http://app1:8000/",
    "http://app2:8000/",
    "http://app3:8000/",
]

def send_insert_request(node_url, user_id, nama, umur):
  try:
    proxy = xmlrpc.client.ServerProxy(node_url, allow_none=True)
    print(
        f"[SIMULASI] Mengirim data ke {node_url} (User ID: {user_id}, Nama:"
        f" {nama})"
    )
    result = proxy.tambah_user(user_id, nama, umur)
    print(f"[HASIL] Respon dari {node_url}: {result}")
  except Exception as e:
    print(f"[ERROR] Gagal terhubung ke {node_url}: {e}")

if __name__ == "__main__":
  print("=== MEMULAI SIMULASI REQUEST KONKUREN KE 3 APP NODE ===")
  target_id = 3
  target_name = "UserKonkuren"
  target_age = 25

  with concurrent.futures.ThreadPoolExecutor(max_workers=3) as executor:
    for i, url in enumerate(APP_NODES):
      executor.submit(send_insert_request, url, target_id, f"Nama_{i+1}", 25)
  print("=== SIMULASI SELESAI ===")
