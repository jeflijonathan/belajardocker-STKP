# #8 Inter-Process Communication Models

## 1. Shared Memory

**Shared Memory** adalah mekanisme IPC di mana sekelompok proses menggunakan blok memori fisik yang sama untuk membaca dan menulis data. Karena tidak ada penyalinan data (_data copying_) antar proses, metode ini sangat cepat dan efisien untuk pertukaran data berukuran besar. Namun, dibutuhkan mekanisme sinkronisasi (seperti Lock) agar tidak terjadi _race condition_.

## 2. Message Passing

**Message Passing** adalah mekanisme komunikasi antar proses dengan cara saling mengirim dan menerima pesan (biasanya melalui antrean/_queue_ atau _socket_). Proses tidak berbagi ruang memori yang sama. Ketika data dikirim, data tersebut disalin dari pengirim ke penerima, sehingga lebih aman dan cocok digunakan antar mesin yang berbeda jaringan.

## 3. Remote Procedure Call (RPC)

Protokol yang memungkinkan suatu program untuk mengeksekusi sebuah fungsi atau prosedur yang berada di komputer/proses lain seolah-olah fungsi tersebut dipanggil secara lokal (_in-process_). Detail kerumitan jaringan (seperti serialisasi data dan koneksi _socket_) disembunyikan dari pengembang.

### 1. `shared_memory.py`

```python
from multiprocessing import Process, Value, Array
import time

def video_frame_writer(shared_counter, shared_buffer):
    for i in range(1, 4):
        time.sleep(1) # Simulasi jeda tangkap frame
        shared_counter.value = i
        shared_buffer[0] = i * 100 # Contoh data sensor/frame ID
        print(f" [Kamera/Writer] Menulis Frame ID: {shared_counter.value}")

def ai_frame_processor(shared_counter, shared_buffer):
    last_processed = 0
    while last_processed < 3:
        if shared_counter.value != last_processed:
            last_processed = shared_counter.value
            print(f" [AI/Reader] Memproses data dari memori bersama: {shared_buffer[0]}")

if __name__ == "__main__":
    counter = Value('i', 0)
    buffer = Array('i', 1)

    p1 = Process(target=video_frame_writer, args=(counter, buffer))
    p2 = Process(target=ai_frame_processor, args=(counter, buffer))

    p1.start()
    p2.start()

    p1.join()
    p2.join()

    print("Selesai memproses frame video.")
```

### 2. `message_passing.py`

```python
from multiprocessing import Process, Queue
import time

def customer_order_service(order_queue):
    orders = ["Nasi Goreng", "Mie Ayam", "Es Teh Manis"]
    for order in orders:
        print(f" [Customer Service] Pesanan masuk: {order}")
        order_queue.put(order) # Mengirim pesan ke antrean
        time.sleep(0.5)
    order_queue.put(None) # Sinyal selesai

def kitchen_chef_service(order_queue):
    while True:
        order = order_queue.get() # Menerima pesan dari antrean
        if order is None:
            break
        print(f" [Dapur/Chef] Sedang memasak: {order}...")
        time.sleep(1)
        print(f" [Dapur/Chef] {order} selesai dan siap disajikan!\n")

if __name__ == "__main__":
    queue = Queue()

    p_customer = Process(target=customer_order_service, args=(queue,))
    p_chef = Process(target=kitchen_chef_service, args=(queue,))

    p_customer.start()
    p_chef.start()

    p_customer.join()
    p_chef.join()

    print("Semua pesanan telah diproses.")
```

### 3. `rpc_server.py`

```python
from xmlrpc.server import SimpleXMLRPCServer

def cek_saldo(nomor_rekening):
    database_rekening = {
        "12345": 5500000,
        "67890": 1250000
    }
    return database_rekening.get(str(nomor_rekening), "Rekening tidak ditemukan")

server = SimpleXMLRPCServer(("localhost", 8000), allow_none=True)
print("Server Bank RPC berjalan di port 8000...")
server.register_function(cek_saldo, "cek_saldo")
server.serve_forever()
```
