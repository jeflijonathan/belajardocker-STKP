# Definition

**A distributed system** is one in which components located at **networked** computers communicate and **coordinate** their actions only by passing messages. Computers that are connected by a network may be spatially separated by any distance. They may be on separate continents, in the same building or in the same room.

**Sistem Terdistribusi** didefinisikan sebagai _"Sebuah koleksi komputer_ **_otonom_** _yang dihubungkan oleh_ **_jaringan_** _dan dilengkapi dengan perangkat lunak (middleware) sedemikian rupa sehingga sistem tersebut terlihat oleh pengguna sebagai sebuah sistem komputasi tunggal yang_ **\*koheren\*\***."\*

**Poin Kunci dari Definisi:**

1. **Otonom:** Setiap node (komputer/server) memiliki prosesor dan memori sendiri, serta dapat bekerja secara independen berupa pembagian (Server App dan Server DB) / pengalihan (Server utama dan Server cadangan) tugas.

2. **Jaringan**: Setiap node harus berinteraksi atau bertukar data melalui jaringan.

3. **Koheren:** Pengguna akhir atau aplikasi tidak perlu menyadari bahwa proses komputasi sebenarnya dipecah dan dijalankan di berbagai mesin fisik yang berbeda.

# Characteristics

## Concurrency

- Beberapa komponen komputasi berjalan secara bersamaan (_concurrent_) di lokasi yang berbeda.

- Setiap node berbagi beban kerja, berkoordinasi melalui pertukaran pesan (_message passing_), dan tidak ada satu node pun yang secara mutlak mengendalikan seluruh sistem setiap saat.

## No Global Clock

- Jaringan komputer memiliki penundaan (_latency_) yang bervariasi.

- Sangat sulit bahkan mustahil untuk membuat semua komputer memiliki waktu/jam fisik yang persis sama hingga orde milidetik.

- Dampaknya: Urutan kejadian (_event causality_) tidak bisa ditentukan murni dari jam fisik, melainkan harus menggunakan mekanisme koordinasi sinkronisasi logis.

## Partial Failures

- Dalam sistem monolitik, jika CPU rusak, seluruh sistem mati.

- Dalam sistem terdistribusi, kegagalan pada satu node, satu komponen jaringan, atau satu pangkalan data **tidak boleh** melumpuhkan keseluruhan layanan. Sistem harus mampu mendeteksi kegagalan, mengisolasinya, dan tetap melayani pengguna.

## Heterogenitas

Sistem terdistribusi modern harus mampu mengintegrasikan berbagai komponen yang berbeda (heterogen) seperti:

- **Hardware:** Kombinasi server _high-end_, PC standar, hingga perangkat _Edge/IoT_ atau ponsel.

- **Sistem Operasi:** Integrasi antara server Linux, Windows, atau macOS.

- **Jaringan:** Komunikasi melalui jaringan kabel (LAN, Fiber Optic) maupun nirkabel (Wi-Fi, 5G) dengan protokol yang berbeda-beda.

- **Bahasa Pemrograman:** Layanan yang dibangun dengan Python harus bisa berkomunikasi lancar dengan layanan yang dibangun menggunakan Java atau Go.

`app.py`

```python
import sys
import socket
import time

mode = sys.argv

# --- SERVER 1 (Penjumlahan + Panggil Server 2) ---
if mode == 'server1':
    s = socket.socket()
    s.bind(('0.0.0.0', 5001))
    s.listen(1)
    print("Server 1 (Tambah & Forward) siap...")
    while True:
        conn, addr = s.accept()
        data = conn.recv(1024).decode().split(',')
        hasil_tambah = float(data[0]) + float(data[1])

        # BARU: Server 1 bertindak sebagai client untuk Server 2
        s2 = socket.socket()
        s2.connect(('server2', 5002))
        s2.send(str(hasil_tambah).encode())
        pajak, total = s2.recv(1024).decode().split(',')
        s2.close()

        # Server 1 mengembalikan semua hasil lengkap ke Client asli
        conn.send(f"{hasil_tambah},{pajak},{total}".encode())
        conn.close()

# --- SERVER 2 (Hitung Pajak 10% - Tetap Sama) ---
elif mode == 'server2':
    s = socket.socket()
    s.bind(('0.0.0.0', 5002))
    s.listen(1)
    print("Server 2 (Pajak) siap...")
    while True:
        conn, addr = s.accept()
        jumlah = float(conn.recv(1024).decode())
        pajak = jumlah * 0.10
        total = jumlah + pajak
        conn.send(f"{pajak},{total}".encode())
        conn.close()

elif mode == 'client':
    time.sleep(2)
    angka1, angka2 = "100", "50"

    s1 = socket.socket()
    s1.connect(('server1', 5001))
    s1.send(f"{angka1},{angka2}".encode())

    hasil_tambah, pajak, total_akhir = s1.recv(1024).decode().split(',')
    s1.close()

    print(f"\n=== HASIL DI CLIENT (POLA CHAINING) ===\nAngka: {angka1} + {angka2} = {hasil_tambah}\nPajak: {pajak}\nTotal: {total_akhir}\n")

```

`dockerfile`

```dockerfile
FROM python:3.10-slim
WORKDIR /app
COPY app.py .
CMD ["python", "app.py"]
```

`docker-compose.yaml`

```yaml
services:
  server1:
    build: .
    command: python -u app.py server1

  server2:
    build: .
    command: python -u app.py server2

  client:
    build: .
    command: python -u app.py client
    depends_on:
      - server1
      - server2
```
